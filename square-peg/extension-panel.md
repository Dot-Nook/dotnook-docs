# Extension panel

The panel has seven buttons arranged horizontally.

1. **User manual**: links to this documentation
2. **Default instance**: generates a new shape layer with the Square Peg effect applied, using basic default styling

Buttons 3–7 are **preset slots**. Each slot can hold a saved Square Peg style.

- **Save a preset**: select a layer containing a Square Peg effect and click an empty slot to save it there
- **Load a preset**: click a filled slot to generate that layer on your timeline
- **Clear a preset**: Opt/Alt-click a filled slot to clear its saved preset
