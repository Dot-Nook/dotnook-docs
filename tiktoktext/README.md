# TikTokText

Recreate TikTok, Reels, Shorts and CapCut-style text directly in After Effects, with dynamic resizing multi-line text boxes using a single text and shape layer.

From v2.1 onwards, an Essential Graphics template is included, allowing automated TikTok text creation in Premiere Pro.

## Styles

TikTokText offers six styles:

- **Stroked Text**: a stroked text style using Layer Styles rather than character stroke, producing smooth corners and letter joins. An expression keeps the stroke width consistent regardless of scale.
- **Boxed Text**: a line-wrapping box on a separate shape layer parented to the text layer. Multiple expressions make the box wrap around individual text lines.
- **Color Accent**: highlights a single word. A slider lets you choose which word is highlighted and control its colour.
- **Box Accent**: similar to Color Accent, but uses a small box around the word instead of colour. A slider controls which word is highlighted.
- **Gentle Glow**: a subtle glow layer style for a CapCut/TikTok look. An expression keeps the glow size consistent with text scaling.
- **Drop-Depth**: a stroked text style with drop shadows that creates a faux 3D drop-depth look.

## Using TikTokText

1. **Select a style**: choose from the six styles in the panel.
2. **Click Create**: generates a text layer and shape layer on your timeline at the playhead position, placed above any currently selected layers.
3. **Customise**: adjust fonts, colours and style-specific controls. Each style avoids preset fonts and colours so you can make it your own. Styles with highlights include expression controllers for adjusting colours and a slider to select which word is highlighted.

> **Note:** When resizing generated text, use the layer's Transform > Scale property rather than adjusting the character font size. This keeps boxes, strokes and glows proportional.
