# Quick start

1. Select one or more text layers in your comp.
<br>
2. Click one of Boxer's five quick start buttons in the extension panel.
<br>
3. Boxer generates a shape layer, pairs it to your text layer, and adds the Boxer pseudo-effect to that shape layer. Use the pseudo-effect controls to adjust sizing, corners and trim.
<br>
4. All standard shape layer options remain available: fill, stroke, gradient, path modifiers and more.
