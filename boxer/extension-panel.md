# Extension panel

The panel has six buttons.

The first button links to this user manual.

The remaining five are quick start buttons. Each one creates a Boxer shape layer and pseudo-effect with a different default style:

1. **Simple filled box**: moderate padding, rounded corners
2. **Pill-shaped stroked box**: no fill, wide horizontal padding, fully rounded ends
3. **Square box**: square corners, both fill and stroke
4. **Underline**: uses Y-offset to shift the box below the text
5. **Message bubble**: three fully rounded corners, one square corner
