# Boxer

Create dynamic, auto-resizing text boxes in After Effects with a single click.

Boxer generates a shape layer paired to your text layer and adds a pseudo-effect for controlling the box's size, corners and trim. The shape layer stays fully editable: fill, stroke, gradient, path modifiers and more are all available through standard After Effects shape layer controls.
