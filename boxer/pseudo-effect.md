# Pseudo-effect

After Boxer creates a shape layer, a pseudo-effect appears on that layer in After Effects' effect controls. This is where you control Boxer's behaviour. The pseudo-effect has three sections: Sizing, Corners and Trim.

## Sizing

- **X-Padding**: Adjusts horizontal padding. Negative values make the box narrower than the text. When Dynamic Width is unchecked, this becomes an absolute width value.
- **Y-Padding**: Adjusts vertical padding. Negative values make the box shorter than the text. When Dynamic Height is unchecked, this becomes an absolute height value.
- **X-Offset**: Shifts the box horizontally from the parent layer's centre.
- **Y-Offset**: Shifts the box vertically from the parent layer's centre.
- **Dynamic Width**: When checked, the shape layer resizes automatically when the text content changes width.
- **Dynamic Height**: When checked, the shape layer resizes automatically when the text content changes height.

## Corners

- **Link Corners**: When checked, the Corner Radius slider adjusts all four corners equally. Uncheck it to access individual corner controls.
- **Corner Radius**: Adjusts the corner radius of all four corners equally (visible when Link Corners is checked).
- **Top Left Radius**: Adjusts the top-left corner's radius.
- **Top Right Radius**: Adjusts the top-right corner's radius.
- **Bottom Right Radius**: Adjusts the bottom-right corner's radius.
- **Bottom Left Radius**: Adjusts the bottom-left corner's radius.

## Trim

Trim controls crop the box from any side. Each slider works independently.

- **Trim Left**: Trims the box from left to right.
- **Trim Top**: Trims the box from top to bottom.
- **Trim Right**: Trims the box from right to left.
- **Trim Bottom**: Trims the box from bottom to top.
