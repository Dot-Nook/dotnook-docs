# dotnook docs

User guides for all dotnook After Effects tools.

## Tools

| Tool | Description |
|------|-------------|
| [Boxer](boxer/README.md) | Dynamic auto-resizing text boxes |
| [QuickFlip](quickflip/README.md) | Flip, rotate and scale layers |
| [Square Peg](square-peg/README.md) | Individual corner controls for shape layers |
| [Variations](variations/README.md) | Create comp variations with different sizes and timings |
| [TikTokText](tiktoktext/README.md) | TikTok, Reels and Shorts-style text in After Effects |
| [Shortcut Studio](shortcut-studio/README.md) | Personal library for expressions, scripts and presets |

## Installation

All dotnook tools are After Effects extensions. See [Installing extensions](installing-extensions.md) for setup instructions.
