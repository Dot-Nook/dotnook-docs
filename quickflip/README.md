# QuickFlip

Instantly flip, rotate and scale layers in After Effects, just like in Illustrator and Photoshop.

## Panel

QuickFlip's panel has ten buttons:

1. **User manual**: links to this documentation
2. **Flip horizontally**: flips selected layer(s) on the x-axis
3. **Flip vertically**: flips selected layer(s) on the y-axis
4. **Rotate counter-clockwise**: rotates selected layer(s) counter-clockwise by the preset amount (default: 90°)
5. **Rotate clockwise**: rotates selected layer(s) clockwise by the preset amount (default: 90°)
6. **Scale down**: scales selected layer(s) down by the preset amount (default: 50%)
7. **Scale up**: scales selected layer(s) up by the preset amount (default: 200%)
8. **Opacity low**: sets selected layer(s) opacity to the preset amount (default: 0%)
9. **Opacity high**: sets selected layer(s) opacity to the preset amount (default: 100%)
10. **Settings**: set preset values for each function and show or hide button pairs

## Keyframe modes

Buttons 2–9 support three modes that control keyframe behaviour:

- **Click**: adds a new keyframe only if the property already has keyframes
- **Shift + click**: always adds a new keyframe, regardless of existing keyframes
- **Opt/Alt + click**: adjusts all existing keyframes without creating new ones
