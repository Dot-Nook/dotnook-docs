# Library

A Shortcut Studio library is a folder on disk that stores all your items as files. Shortcut Studio reads from and writes to this folder whenever you add, edit or delete items.

## Default location

The default library location is your Documents folder. You can change this in [Settings](settings.md).

## Item types

The library supports three item types:

- **Expressions**: After Effects expression code. Applied directly to selected layers when you double-click.
- **Scripts**: `.jsx` or `.js` files. Executed in After Effects when you double-click.
- **Presets**: After Effects `.ffx` preset files. Applied to selected layers when you double-click.

## Item metadata

Every item is stored with the following metadata, all of which is searchable and sortable:

- **Name**: how the item appears in the library
- **Icon**: a visual identifier shown on the card or row
- **Colour**: a colour applied to the icon for quick visual scanning
- **Description**: freeform notes about what the item does
- **Tags**: keywords used when searching the library
