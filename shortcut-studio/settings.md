# Settings

Click the folder icon at the top-right of the panel to open Settings.

## Library location

The **Library Path** field shows where your library is currently stored. Click **Change** to update the path.

> **Note:** Changing the library path in Settings updates where Shortcut Studio looks for your files. It does not physically move your files. Move the folder on disk first, then update the path in Settings.

## Using a shared or cloud library

You can point your library at a folder synced via iCloud Drive, Dropbox or any other service. This lets you access the same library across multiple machines. Each machine needs Shortcut Studio installed and pointed at the same folder path.
