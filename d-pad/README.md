# D-Pad

Move anchor points, align layers and attach nulls with one click.

D-Pad is a tiny panel with a nine-point pad and three modes. Pick a mode, select your layers, press a direction. Rotated, scaled, parented, 3D and keyframed layers all stay exactly where they should.

## The panel

- **Mode switcher** (top): click to cycle between **Anchor Point**, **Position** and **Attach Null**
- **The pad**: nine buttons, one for each corner, edge and the centre
- **Footer**: one or two extra actions that change with the mode

Hover over any button for a reminder of what it does.

## Opt/Alt + click

Every button has a second action. Hold **Opt** (Mac) or **Alt** (Windows) and the buttons turn green to show the alternate actions are armed.

| Mode | Click | Opt/Alt + click |
|------|-------|-----------------|
| Anchor Point | Move the anchor point, layer stays in place | Move and freeze the anchor point |
| Position | Move the layer to that point (2+ layers: align them) | Move each layer's anchor point to that point of the comp |
| Attach Null | One null per layer | One null for the whole selection |
