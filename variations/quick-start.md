# Quick start

1. **Select compositions**: select the comp(s) you want to create variants of in your After Effects project panel.
2. **Name the variant(s)**: set an exact name, or build the name dynamically using find & replace, add before or add after options.
3. **Set the location**: define an absolute folder path or a relative path based on the original composition's location.
4. **Configure frame rate**: choose whether to set a new frame rate for the variant.
5. **Adjust duration**: set an exact duration or add/subtract from the original comp's duration.
6. **Change dimensions**: choose whether to change the dimensions of the variant, using exact values or relative adjustments.
7. **Handle precompositions**: decide whether to duplicate and relink precomps. Frame rate, duration and dimension changes can be applied to precomps as well.

For a full breakdown of every option, see the [full guide](full-guide.md).
