# Installing extensions

## Using the aescripts manager (recommended)

The easiest way to install any dotnook tool is through the [aescripts + aeplugins manager app](https://aescripts.com/learn/aescripts-aeplugins-manager-app/). It handles installation, updates and licence activation in one place.

## Manual install via ZXP installer

Download the `.zxp` file for the tool from your aescripts account. Then use a ZXP installer to install it. aescripts provides one at [aescripts.com/learn/zxp-installer](https://aescripts.com/learn/zxp-installer/).

After either method: restart After Effects. Find the extension under **Window > Extensions > [Tool Name]**.

## Version compatibility

Tools that use After Effects `.ffx` pseudo-effects (Boxer, Square Peg) require **After Effects 2023 (v23) or newer**.
